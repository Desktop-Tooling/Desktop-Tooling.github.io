= Adaptive Thumbelina diagrams

The Live ISOs, Installed OSes, and Both partition layouts now have editable Mermaid sources and explicit Themed SVG manifests.
Each public `name.svg` remains a standalone light/dark image for no-script and failed-load cases.
On the demo pages, the same-origin host sibling is sanitized and inserted only after it loads successfully.

The former fixed dark artwork remains beside each source as `name.legacy-fixed.svg`.
Repository scripts regenerate both output modes and CI verifies that committed artifacts remain fresh.
